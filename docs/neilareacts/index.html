A self-hosted media server that ran on a Linux Mint box under the TV.

A Node media server I wrote for myself: one folder of films and shows, a web page to play them from any device on the network, and a service file so it came back after a reboot.

It worked. It also needed me to keep the box on, keep the library tidy and keep fixing small things, and at some point I stopped doing all three.

Cause of death: lost interest in maintaining it.
