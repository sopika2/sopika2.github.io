Site Archive

since 2026

One command documents a whole website before a redesign: text, screenshots, sitemap, broken links.

A command-line tool for the moment before a website is rebuilt and nobody has a record of what was there. Point it at a site and it produces a Word document with every page's text in reading order, full-page screenshot PDFs for desktop and mobile, an Excel sitemap with every page's title, URL, parent, depth and word count, a broken-link report with the pages that link to each dead URL, and an offline HTML index tying it all together.

I offer this as a website audit service for site owners and agencies planning a redesign: a content inventory, a broken-link report and page screenshots, delivered in one to four days depending on the size of the site.

Python and Playwright. The largest run so far covered 194 pages and found four broken links.
